Accessibility

How Prospect is making its website easier to use with keyboards, assistive technology and reduced-motion preferences.

Prospect Partnership LtdCompany No. 15277481England & WalesUpdated 23 September 2026

CONTACT

Questions about this page can be sent to founder@prospectpartnership.co.uk.

Prospect aims to make this website usable by as many people as reasonably possible and to improve it as the site develops.

What we have implemented

  • A skip-to-content link for keyboard users.
  • Visible keyboard focus states.
  • Semantic headings, navigation labels and text alternatives for meaningful images and logos.
  • Improved text and accent-colour contrast.
  • No unnecessary scroll-reveal or cursor animations.
  • A responsive layout for smaller screens and zoomed views.

Known limits

We do not claim that every page has been independently certified to a particular accessibility standard. The site is small and evolving, so we will continue to test and fix issues as they are found.

Report a problem

If you have difficulty using any part of the site, email founder@prospectpartnership.co.uk and tell us which page or feature caused the problem. We will try to provide the information in an accessible alternative format where practical.
